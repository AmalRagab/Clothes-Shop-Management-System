# Clothes Store System

A simple Java application to manage a clothes store, including inventory, products, and categories.

## Features
- Add, update, and delete clothes products
- Categorize products
- Track product stock and availability
- Simple console-based interface for demonstration

## Technologies
- Java
- OOP concepts: classes, inheritance, polymorphism
- SQL for saving/loading data
